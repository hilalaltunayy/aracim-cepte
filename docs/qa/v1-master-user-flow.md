# V1 ana kullanıcı akışı denetimi

**Audit date:** 2026-08-01
**Kapsam:** 35 kanonik kullanıcı işlemi
**Kanıt düzeyi:** Kaynak kod + mevcut Vitest + [V1 release kapıları](../release/v1-release-gates.md)

## Durum sözlüğü

- **PASS:** İlgili kaynak/test kanıtı denetlenen alt sözleşmeyi destekliyor.
- **POSSIBLE RISK:** Kaynakta risk var; runtime/ürün kararı olmadan defect kesinleştirilemiyor.
- **CONFIRMED DEFECT:** Kaynakta deterministic yanlış/eksik yol veya hesaplanmış kontrast ihlali var.
- **MANUAL ANDROID CHECK REQUIRED:** Native/runtime/gerçek servis sonucu repository ile kanıtlanamaz.
- **HUMAN DECISION REQUIRED:** Ürün, hukuk veya release owner kararı gerekiyor.

## Akışlar arası confirmed defect özeti

1. **Mileage downgrade:** Araç edit current kilometreyi sessizce düşürebiliyor.
2. **Mileage due state:** Hedef kilometreye tam eşit durumda `Due` yerine `overdue` üretiliyor; ayrıntı
   [acceptance matrisinde](v1-acceptance-test-matrix.md).
3. **Attachment open error:** Signed URL/viewer/ağ hatası kullanıcıya yakalanmış mesaj üretmiyor.
4. **Offline cold start:** Bootstrap hatası “araç yok” ile karışıyor.
5. **Session expiry:** Global protected-route redirect/guard yok.
6. **Record + mileage:** İki DB adımı atomik/idempotent değil; retry duplicate/partial state riski.
7. **Reminder + notification:** Local OS notification ile DB mutation failure'da ayrışabiliyor.
8. **Storage + metadata:** Silme/replacement sırası failure'da orphan veya missing object bırakabiliyor.
